🛍️ FluxStore

FluxStore is a modern mobile e-commerce application built with React Native, designed to deliver a smooth, fast, and user-friendly shopping experience. The app provides essential e-commerce features with a clean and responsive UI optimized for mobile devices.

🚀 Features

📦 Product Browsing – Explore products with a clean and intuitive layout

🔍 Search & Filtering – Quickly find products based on categories or preferences

🛒 Shopping Cart – Add, update, and remove items from the cart

🔐 User Authentication – Secure login and account management

📱 Responsive UI – Optimized for performance and usability across devices

🛠️ Tech Stack

React Native – Cross-platform mobile development

JavaScript / TypeScript – Application logic

Expo – Simplified development and testing

REST APIs / Backend Services – Product and user data management

📂 Project Structure
FluxStore/
├── assets/        # Images, icons, fonts
├── components/    # Reusable UI components
├── screens/       # App screens (Home, Cart, Checkout, Auth, etc.)
├── navigation/    # Navigation configuration
├── services/      # API and data handling
├── utils/         # Helper functions
└── App.js         # App entry point

▶️ Getting Started
Prerequisites

Node.js

npm or yarn

React Native CLI or Expo CLI

Installation
git clone https://github.com/Celyah02/FluxStore.git
cd FluxStore
npm install

Run the App
npm start
